# Проверки дополнения Tuman 2.1.2

Проверки: 23–24 октября 2026 года. Номер версии сохранён: versionName 2.1.2 / versionCode 20102.

## Сборка и автоматические проверки

- `:buildSrc:test :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:lintRelease --offline` — BUILD SUCCESSFUL.
- 35 JVM-тестов, без ошибок: 20 тестов адресов/поиска, 6 тестов очистки ссылок, 6 тестов профилей защиты, 3 теста адаптации разрешений Gecko.
- Debug и оптимизированный R8 release собраны для arm64-v8a, armeabi-v7a и x86_64. Для установки поставляются подписанные debug APK; release APK остаются неподписанными.
- Debug/release Lint: 0 ошибок, 1 прежнее предупреждение OldTargetApi (targetSdk 36).
- Подпись ARM64 APK проверена apksigner; SHA-256 сертификата совпадает с предыдущей поставкой: ef9076383379f6179455a07846b5849e07f2a0e1d9e531dc4b36ccf262a372dc.
- Проверены versionName/versionCode, ABI и разрешения манифеста. Новые системные разрешения не добавлены.
- Обновление APK установлено поверх предыдущей сборки в эмуляторе; настройки сохранены.

## Проверки дополнения в эмуляторе

Отдельный эмулятор Android API 37 / x86_64, 720×1600, 320 dpi. Управление через ADB и UI Automator. Сохранение настроек дополнительно проверялось чтением DataStore тестового экземпляра.

- Перед Maximum появляется предупреждение. «Оставить текущую» сохраняет Strict, подтверждение включает Maximum. В Maximum категории защиты отображаются включёнными и недоступными для ослабления.
- Все пять категорий трекеров переключаются и сохраняются. Тесты ProtectionPolicy проверяют соответствующие флаги движка и приоритет Maximum.
- На официальной [тестовой странице Mozilla](https://mozilla.github.io/tracking-test/etp-test.html) щит получил 6 реальных событий блокировки уникальных ресурсов и показал домены источников. TLS-индикатор показал зашифрованное соединение. Это проверка обработки реальных событий, а не заявление о прохождении всех проб страницы: часть её проб, включая fingerprinting, не показала блокировку на этой версии списков/движка.
- На контролируемой HTTPS-странице настройка «Блокировать все cookies» даёт COOKIE OFF. Возврат к изоляции сторонних cookies даёт COOKIE ON для cookie собственного сайта.
- На той же странице с коротким встроенным WAV запрет автозапуска приводит к NotAllowedError. Отключение запрета даёт успешный play(); повторное включение снова блокирует, в том числе после ранее выданного разрешения.
- Входящий адрес `https://example.com/?utm_source=tuman&keep=yes#hello` открывается как `https://example.com/?keep=yes#hello`. Сохранение остальных параметров и фрагмента также покрыто тестами.
- Все шесть палитр выбираются и сохраняются; Forest визуально проверена на экране настроек. Существующий светлый/тёмный режим сохранён.
- Приветствие записано на видео; последовательные кадры показывают появление текста, знака и кнопки. Движение тумана проверено сравнением кадров: при выключенных анимациях фон пиксельно совпадает через две секунды; при включённых среднее изменение составляет около 1/255 по цветовым каналам за три секунды.
- Карточки сайта студии, GitHub и Telegram отображаются во вкладке «Официальное». Адреса владелец ещё не предоставил: карточки явно недоступны, переходы по реальным адресам не проверены.
- Лицензии открываются офлайн из «О приложении». В APK и исходниках сохранены полный исходный notice из закреплённой версии GeckoView, тексты лицензий и перечень зависимостей.
- Исправлены скрытие панели браузера при прокрутке настроек, цвета поверхностей модальных панелей и повтор приветствия без создания второго MainActivity. Возврат из повторного приветствия на прежний экран «О приложении» проверен в эмуляторе.

## Материалы

Актуальные логи, XML-результаты 35 тестов, списки проверок, снимки и запись приветствия находятся в `validation/addon/`. Файлы в корне `validation/` относятся к предыдущему этапу 2.1.2, до этого дополнения. Предыдущая поставка отдельно сохранена в соседней папке `Tuman-2.1.2-before-addon/`.

## Границы проверки

Физические телефоны и старые версии Android не тестировались. Не проводились полный аудит трафика, испытания всех сайтов или всех внешних списков Safe Browsing. Фоновая пауза подключена к API Gecko, но отдельный длительный медиатест в фоне не проводился. Защита зависит от классификации адресов движком и не блокирует всю рекламу или все способы отслеживания. Особенности и ограничения описаны в README.
