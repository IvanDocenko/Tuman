# Tuman

An Android browser by **Lunarium Studio**, featuring a customizable interface and tracking protection.

**Version: 2.1.4 · Android 8.0 or later**

[Download Tuman](https://github.com/IvanDocenko/Tuman/releases)

## Features

- Multiple themes and appearance settings.
- Smooth animations that can be disabled.
- Address bar placement at the top or bottom.
- English and Russian interface languages.
- A choice of search engines, with support for custom providers.
- Configurable tracking protection.
- Option to set Tuman as your default browser.
- Privacy policy available within the app.

## Installation

1. Open the [Releases](https://github.com/IvanDocenko/Tuman/releases) page.
2. Download an APK. Choose **arm64-v8a** for most modern Android phones.
3. Open the downloaded file.
4. If prompted by Android, allow installation from this source and confirm installation.

The current 2.1.4 build is intended for testing and is signed with a debug key.
