# Проверки Tuman 2.1.3

Проверки: 24–25 октября 2026 года. versionName 2.1.3 / versionCode 20103.

## Объём изменений

Авторство Lunarium Studio / Daniil Ignatiev; системный выбор браузера по умолчанию; офлайн-политика конфиденциальности RU/EN; удаление Bing и зависимость Yandex от языка; выделение URL при фокусе; независимое положение адресной панели; выбор панели в приветствии; понятное название переключателя анимаций; обновлённые сообщения в ресурсах.

## Сборка

Команда: `:buildSrc:test :app:assembleDebug :app:testDebugUnitTest :app:lintDebug :app:assembleRelease :app:lintRelease --offline`.

BUILD SUCCESSFUL. Debug/release Lint: 0 ошибок, 1 прежнее предупреждение OldTargetApi (targetSdk 36). Сертификат подписи совпадает с предыдущими версиями; APK поддерживает обновление поверх 2.1.2.

42 JVM-теста без ошибок: 35 прежних и 7 новых тестов доступности поисковых систем, миграции Bing и смены языка при выбранном Yandex. Debug и R8 release собраны для arm64-v8a, armeabi-v7a и x86_64. Для установки поставляются подписанные debug APK; release не подписан ключом публикации.

Актуальные логи, подпись, сведения APK, XML-результаты, список проверок и снимки находятся в `validation/2.1.3/`. Материалы предыдущих этапов находятся в корне `validation/` и `validation/addon/`.

## Эмулятор

Android API 37 / x86_64, 720×1600, плотность 320 dpi. Обновление установлено поверх 2.1.2 с сохранением данных. Использованы ADB, UI Automator и чтение DataStore тестового экземпляра. Для части проверок системных экранов анимации эмулятора временно отключались.

- Перенос адресной панели кнопкой вверх/вниз сохраняет выбор и меняет реальные координаты панели; вкладки остаются снизу. Снимки визуально проверены.
- Первый тап по URL, затем ввод нового адреса без предварительного удаления или Ctrl+A заменяет адрес полностью; переход не увеличивает число вкладок.
- Авторство и сообщения о будущем появлении официальных ссылок проверены в UI.
- Политика конфиденциальности открывается локально; данные описаны по конфигурации приложения и движка. Контактные адреса не выдуманы, сроки появления ресурсов соответствуют указанию владельца.
- Отмена системного запроса оставляет Chrome браузером по умолчанию; подтверждение назначает Tuman. Кнопка выбора другого браузера открывает настройки Android, где успешно возвращён Chrome. Роль проверена через системный RoleManager, статус в Tuman обновляется после возврата.
- В русском интерфейсе Yandex выбирается и сохраняется. После перехода на английский сохраняется DuckDuckGo; в английском меню Bing и Yandex отсутствуют. Миграция сохранённого значения BING дополнительно покрыта JVM-тестом.
- Политика открывается на русском и английском, имена и подпись «Тестеровщик» отображаются правильно. Исправлен чрезмерно крупный заголовок русской политики на узком экране.
- Выбор верхней адресной панели на третьем шаге приветствия сохраняется и применяется после выхода. Переключатель «Анимации интерфейса» сохраняет выключенное и включённое состояние.
- Повторный запуск финального APK сохраняет русский язык, верхнюю адресную панель и включённые анимации.
- Подробный список — в `validation/2.1.3/emulator-checks.txt`.

Системный выбор реализован через [Android RoleManager](https://developer.android.com/reference/android/app/role/RoleManager), на Android 8–9 — через настройки приложений по умолчанию. Выбор другого браузера всегда передаётся Android.

## Границы проверки

Физические телефоны и Android 8–9 отдельно не проверялись. Не проводился повторный полный аудит сетевого поведения движка: изменения безопасности и приватности в этой версии касаются описания текущего поведения и системного назначения браузера. Предыдущие функциональные проверки защиты сохранены в отчёте 2.1.2. Политика описывает фактическую конфигурацию версии 2.1.3 и не является заявлением о сертификации приложения.
